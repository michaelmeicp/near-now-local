# Near Now｜附近小旅行時段表
**v0.1.0 · 離線互動示範 · 繁體中文**

用「什麼時候能出發」來選小旅行。不用註冊、不取用定位，不對外聯絡。地區、步程、場地、導覽、營運者及其公告皆為原創合成資料，不是真實供應或預約服務。

## 開始
直接以現代瀏覽器開啟 `index.html`。若想用固定網址測試本機儲存，可在本目錄執行 `python3 -m http.server 8080 --bind 127.0.0.1`，然後開啟 http://127.0.0.1:8080 。不需建置、套件安裝或連線至外部服務。

## 怎麼看
- 「示範現在」固定為 **2026-11-18 10:20，Asia/Taipei**。涵蓋 11/18 至 11/24 七天。切換日期只是在選集合日，不會改變判讀資料狀態的基準。
- 日期、時段、活動長度、集合區、親子與體力條件可以組合篩選。手選出發區不改變結果，只提供虛構區域中心間的粗估步程。無座標的跨區路線顯示待查。
- 清楚開放的示範場次以外，另列滿額、取消、暫停、天氣待確認、待查及已過集合時間。核對逾／達 48 小時、缺核對時間或印證不足，不推定開放。11/18 山坡的聲音地圖是舊資料例；11/20 只有待查；11/24 沒有場次。
- 開啟詳情可查看集合點、來源摘錄、核對與更新時間。存入行程是本機的規劃筆記，不會變動名額。儲存失敗則僅在當次頁面保留。可移除與匯出純文字。沒有推播、購票、即時天氣、外部地圖或後台。
- 試存 11/18「夜港燈標觀察」和 11/19「午夜海面筆記」：集合日期不同仍會提示時間重疊。緊接的首尾時間不視為衝突。

## 架構與驗證
- `index.html`、`style.css`：行動版優先版面、原生控制項與對話框；`assets/` 內 SVG 圖稿為本作原創。
- `model.js`：合成資料、場地時區、狀態／舊資料判讀、區域步程、過濾、重疊及儲存規則。
- `app.js`：時間軸、詳情、本機行程及文字下載，沒有網路請求。
- Node 18+：執行 `npm test`（不需 npm install）。亦可用 `TZ=America/Los_Angeles node --test *.test.js` 檢查裝置時區不同時的結果。GitHub Actions 使用同一測試命令。
- 人工檢查：390px 視窗、鍵盤 Tab／Enter／Escape、重設篩選、加入兩個衝突場次、重載及移除、跨日與缺資料、禁止儲存時的回饋。此版本並非上線營運服務。
